# SUIJI Shopify

## Required design standard

Read and follow [DESIGN.md](candidates/2026-11-01-website-v2-29d86a06/DESIGN.md) before planning, editing or publishing any SUIJI Shopify change. It applies to theme code, theme-editor settings, app embeds, forms, navigation, pages, translations, products and collections, prices and availability, and imagery. Apply the relevant rules to every customer-facing result across previews and the live store.

Reuse the shared SUIJI components, tokens and approved assets. Use the latest direct user instruction when it revises a design requirement, and update the canonical DESIGN.md as part of that change. Existing write and publication authorization continues to apply.

Before handoff or release, verify the affected presentation and behavior in English and French on desktop and mobile. Use the DESIGN.md verification matrix for layout and shared-style changes. Run its design contract check for a theme patch. Keep the canonical file and the workspace copy in sync.
