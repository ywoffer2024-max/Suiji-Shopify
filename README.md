# Suiji-Shopify

The current maintained Shopify source is `theme/`. Its required design contract is the root `DESIGN.md`; run `python3 maintenance/rev107/check_design_contract.py` before preparing a theme change. `maintenance/rev107/photo-publication-20261117.json` records approved native identities and current image bindings, including the 18 November supplement.

Historical candidates, backups and snapshots preserve prior versions. They do not override the current root design contract. Release and deployment state are recorded separately: a source commit is not proof that a theme has been published.
