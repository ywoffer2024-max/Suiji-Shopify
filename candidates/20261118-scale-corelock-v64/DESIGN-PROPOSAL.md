# SUIJI v6.4：构图与 Core-Lock 页面提案

本文件是内部提案。正式规范仍为 DESIGN.md v6.3.17；本预览没有改动正式站布局、颜色或购买状态。

## 需要先解决的问题

| 优先级 | 位置 | 当前问题 | 提案 |
| --- | --- | --- | --- |
| 高 | 商品照片 | 部分真实圆弧呈宏观折线；戒指背面小钻／镶口有强反光反馈 | 由原制作负责人修源或局部高光，独审后替换确切 SKU／机位。页面缩放、CSS 和 AI 不能冒充几何已修好 |
| 中 | 混合商品列表与菜单 | 单品先归一到接近相同的主体大小，再微调戒指，仍把小花饰、戒指与大项圈放到近似视觉等级 | 按品类和使用场景设视觉尺度；统一的是图片框和信息基线，不是每件首饰的主体大小 |
| 中 | Core-Lock 入口 | 单个产品、两个大圆形入口与大标题竞争；用户难以看出系列范围 | 用真实多件 Bases 与多石色 Charms 两组自然摆放照片；去掉大圆框；主标签在图片下方 |
| 中 | Core-Lock 介绍页 | 介绍之后仍要多次跳转才能看到可选件 | 简短解释三种部件关系，保留操作方法；同页直接列底托与全部当前兼容花饰 |
| 中 | 全站视觉节奏 | 色彩、主图尺度与文字层级同时均匀，缺少购物重点 | 图片主导，缩短集合页介绍，主要动作靠近商品；一个浅色内容带形成节奏；先不换字体或全站上红 |

## 图片尺度：保持形状，区分角色

卡片仍为 4:5；同一行的名称、价格与状态保持相近位置。只对整张已批准图片等比显示，不改产品几何，不借用其他款式，不把屏幕像素说成实际尺寸。

预览中的值是针对当前这几张源图的 CSS 候选参数，尚未完成浏览器及主体包围框测量；不能把它们直接升级为所有图片的通用生产标准。

| 场景 | 显示方向 | 预览中的候选 |
| --- | --- | --- |
| 混合列表：戒指 | 留出明确呼吸感，避免像巨型雕塑 | 当前 R01 图从约 1.784 的显示缩放调整为 1.38 |
| 混合列表：耳环 | 一对作为一个整体，主体略大于小戒指 | 当前 H01 图从 1.84 调整为 1.25 |
| 混合列表：项圈 | 保留完整轮廓和连接细节，比小件占更大范围 | 当前项圈图从 1.109 调整为 1.02；因原图构图不同，不能直接比较数字大小 |
| 混合列表：花饰 | 不把小石饰放到和项圈一样大 | 当前花饰用约 0.9；各形状仍需逐图检查 |
| 套装 | 完整、清楚地交代包含物 | 保留整套图的原有相对关系，不分别放大其中一件 |
| 商品详情 | 比卡片更大，能看清纹理；与放大查看分工 | R01 独立白底图台、同源放大；手机仍保留 38svh 上限。最终用实际主体边界确认留白 |
| 多件组照 | 自然落桌，统一摄影与真实相对尺度 | 需真实模型同场景出图；当前独立商品图片排布只是明确标注的内部占位 |

项链可以试自然盘绕的主图，但必须保留真实链节和双焊连接；展开全貌与长度信息仍保留为后续图。未收到合格同源盘绕图之前，不用旧图或改变链条形状来代替。

## Core-Lock：先看得懂，再直接选

页眉悬浮菜单保留两个入口：Bases、Charms / Ornements。两张组照各自承载一类产品，主标签位于图片下方，不在每件小图旁堆字。菜单中不使用两个放大的圆形泡泡。

介绍页按以下顺序：

1. 紧凑标题和一段解释：base 是佩戴的首饰托；Core-Lock 是连接搭扣；charm 是可替换的花饰。
2. 两张组照入口，直接锚定本页可选区。
3. 三个短步骤与操作帮助，明确“包含物”和“兼容性”是不同事实；不是每一款都采用同一种连接。
4. 可选底托、各品类入口与尺码帮助。
5. 全部当前已发布、图片通过的兼容花饰；各自指向真实商品页。

组照资产预留 `bases`、`charms` 两个可替换位置。照片应包含不同真实底托、多种真实石色花饰；不能将几张独立主图缩放拼贴后称为同场景合影。

## 字体与颜色

保留已确认的方标配字标、Newsreader 400、Manrope、矩形控制和既有断点。提升精致感优先靠构图、阅读层级、密度、材质与真实照片。

默认预览继续使用正式站的蓝灰色角色；另提供“少量酒红点缀”对比：深酒红 `#7B424B` 只放在主动作与少量强调，浅暖珠白 `#F4EFEC` 用于一个说明区。产品图台与页眉保持白色，不把钛和宝石染成暖色，不铺满全站红色。

静态颜色计算结果见 contrast-measurements.json。白字在酒红色上为 7.71:1、主文字在浅暖珠白上为 9.36:1；这是声明色值的计算，尚未取浏览器实际渲染像素。

## 当前预览边界与验收

预览包括首页、Core-Lock 页、混合列表、戒指详情，支持英法切换、390px 手机宽度、菜单、分类过滤、尺码选择、尺码帮助、同源放大和九款花饰入口。它不会下单、发邮件、改 Shopify 或订阅用户。

已做 JavaScript 语法、HTML 控制与 ID、价格来源、图片来源、颜色对比和无外部脚本检查。原生浏览器控制在本轮不稳定，完整 320/360/390/768/1024/1280/1440、断点、200% 缩放及 Safari 实机矩阵尚未完成，不把该预览列为正式站视觉验收通过。

上线前仍需真实组照和受影响产品图通过复核；逐项完成英法电脑／手机呈现与交互检查；再把获采用的规则写入同版仓库与 workspace DESIGN.md。当前正式合同不因这个提案自动变更。
