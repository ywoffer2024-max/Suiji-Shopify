# SUIJI AI 花饰：工厂与原生模型资料模板 v1

目标：最终能做成实际首饰，并交付工厂认可的打印文件。当前支持准备树脂打样与直接金属打印两条路线；具体数值由工厂/工程负责人确认，空白不当作默认通过。

## A. 两条路线都需要

| 字段 | 请提供 / 确认 |
|---|---|
| 工厂 / 工程负责人 | 联系人、工艺负责人、审核日期 |
| 已批准底托及连接件 | 原生 3DM/STEP/其他源文件，修订号、真实尺寸单位、来源、批准证据；网站图片不能代替 |
| 接口 | 对应产品/尺寸、连接件身份、固定与活动件、装配轴、关键配合面、禁止变更区域 |
| 关键尺寸表 | 名义值、公差、测量方法、测量阶段；装配后的间隙/扣合/活动范围要求 |
| 花饰可设计区 | 最大外廓/高度/重量或重量目标、与手指/戒臂/搭扣的避让、边缘/背面要求 |
| 石件与框 | 实际石种/切形/尺寸及公差、固定方式、石座/框的接触与间隙、分件 BOM；不从颜色推断矿物 |
| 表面 | 抛光/纹理/阳极氧化等实际方案、加工余量和关键面不得损伤的要求 |
| 接受的文件 | STL/3MF/STEP/3DM 的具体要求、分件方式、毫米单位及需要的工程图；实际接收软件名称/版本 |
| 验收 | 外观、关键尺寸、连接功能、表面和装配检验；首件签核人及判定标准 |

## B. 树脂打样 profile

| 字段 | 待确认 |
|---|---|
| 用途 | 外形/比例、配合、装配演示、其他；不是默认最终功能件 |
| 打印系统 | 机器型号、树脂具体名称与批次/版本、层厚、切片软件及版本 |
| 设计限制 | 允许壁厚/最小细节/孔径/间隙，按朝向与功能区分；不要只给一个通用数字 |
| 支撑与排液 | 支撑接触位置、孔/封闭腔、清洗和后固化要求 |
| 补偿 | 是否需要；由谁在何阶段做，避免 CAD 与切片重复补偿 |
| 样件测量 | 打印/后处理后关键尺寸，量具、照片、与实物底托装配情况 |

## C. 直接金属打印 profile

| 字段 | 待确认 |
|---|---|
| 材料 | 具体钛合金/其他合金及供应规范；不要只写“钛” |
| 工艺 | 工厂采用的机器、打印工艺、参数/资格版本和层厚 |
| 设计限制 | 壁厚、最小筋/孔/间隙、悬垂及封闭腔规则；接口和外观区分开 |
| 支撑 / 取粉 | 支撑、脱板、粉末排出与清理的可达性；不可把支撑焊在不允许受损的配合面 |
| 变形与热处理 | 工厂要求的余量、补偿、朝向、热处理与后续测量阶段 |
| 后处理 | 接口精加工、去支撑、抛光及上色后最终尺寸要求和边缘处理 |
| 首件 | 样件追溯号、工艺批次、关键尺寸实测、反复装配/保持力/活动功能及外观评审 |
| 批量复用条件 | 材料、机器/参数、源版本、表面工艺变化后哪些需要重新验证 |

## D. 文件交付约定

1. 提供无支撑的成品设计几何与独立工艺文件；是否同时提供带支撑/切片工程由工厂决定。
2. 打印交换文件用工厂确认的 STL 或 3MF；3MF 明确 `unit=millimeter`，STL 附 mm 尺寸说明。
3. 带可编辑工程源、关键尺寸表、BOM、工艺 profile 修订及审核记录。源若是网格就如实标注，不把网格包装成 STEP 当作精密 CAD。
4. 工厂收到文件后在实际软件重新打开、核尺寸与分件；原生工程和导出文件哈希关联。
5. 树脂结果和金属结果独立签核。样件用文件不得混称已批准量产文件。

此模板没有预填壁厚/公差、没有自动选定工厂或合金，也不包含账户凭据。
