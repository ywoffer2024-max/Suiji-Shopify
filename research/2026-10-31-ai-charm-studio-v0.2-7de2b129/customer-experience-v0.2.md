# 顾客端：设计、搭配、提交与沟通

PRD v0.2 的顾客页面规范。本文供内部实施，不是把 PRD 放到实际网站上。

## 页面要帮助顾客完成什么

顾客用自己的想法设计花饰，看与 SUIJI 底托的搭配，提交所选设计，再收到审核结果；需要进一步确认时，与设计师通过邮件沟通。

页面主流程：**选底托 → 设计花饰 → 搭配/修改 → 填邮箱提交 → 审核进展 → 邮件确认。**

## 页面只保留这些区域

| 区域 | 顾客可见内容 |
|---|---|
| 开始 | 一段介绍、一张合适产品图、「设计你的花饰」入口 |
| 设计 | 当前底托、文字描述、参考图（可选）、对当前款有效的风格/轮廓/纹理/颜色选项 |
| 搭配 | 花饰方案与底托预览、切换或局部修改、保存方案 |
| 提交 | 联系邮箱必填、需求备注；称呼可选，已有底托信息按需要补充 |
| 提交结果 | 设计编号、选定方案、邮箱、审核进展与下一步 |
| 相关帮助 | 怎样提交、审核后怎样联系、如何补充或确认设计；联系客服 |

不在顾客页面展示 skill、Tripo/API、模型版本、工厂参数、审核评分、生产检测面板、成本后台、管理员/设计师操作、内部 PRD 或研究资料。也不加入与本次设计无关的问卷、游戏、订阅或其他功能。

## 审核后顾客会看到什么

| 情况 | 页面状态 / 下一步 |
|---|---|
| 刚提交 | 「设计审核中」；告知结果会发到填写的邮箱 |
| 简单且在已验证范围内，AI 审核通过 | 「可以制作」；发送结果邮件，随后确认真实报价、交期与制作安排 |
| AI 不能自动通过、复杂、不确定或资料不全 | 「设计师确认中」或「请补充信息」；设计师邮件联系 |
| AI 通过后发现不可行 | 转「设计师确认中」；邮件说明需进一步确认，不继续沿用原审批安排制作 |
| 设计师提出修改或补充需求 | 「待你确认」；顾客通过邮件/对应设计链接补充与确认 |

简单设计无需每单强制等设计师人工审批。已验证的工艺和结构范围由内部规则保证；顾客不需要判断哪种机器、公差或参数适用。

## 顾客端短文案

**介绍**：把你的想法变成一款花饰，看看它与你的 SUIJI 底托如何搭配。

**预览说明**：这是设计预览。提交后，我们会审核结构和制作方式；如需进一步确认，设计师会通过邮件与你沟通。

**提交成功**：已收到你的设计。审核结果会发送至你填写的邮箱；如需调整或补充信息，设计师会通过邮件与你确认。

**转设计师**：我们需要进一步确认这款设计。设计师会通过邮件与你讨论细节和可行方案。

**通过后需复核**：我们在后续确认中发现一些细节需要调整。设计师会通过邮件与你确认方案，再安排下一步。

这些文案不显示审核分数、模型或接口报错，也不先承诺未经确认的价格、交期或生产结果。界面 EN/FR 对照见完整 PRD。

## 简单的页面草图

| 左侧 / 上方 | 右侧 / 下方 |
|---|---|
| 当前花饰与底托预览 | 选择底托 |
| 批准主视与必要角度 | 描述想法、选择风格/颜色 |
| 选择一个方案继续修改 | 保存 / 提交设计审核 |

手机按「预览 → 有效选项 → 提交」排列。提交前展示选定方案和邮箱，避免把错误版本发去审核。提交后保留设计编号与邮件沟通入口。
